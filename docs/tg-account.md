# Чтение каналов через аккаунт Telegram

## Зачем

Бот берёт посты из Telegram-каналов (Nexvlsz, Advance и другие). Без аккаунта
он читает их через веб-страницу `t.me/s/<канал>`. Она не отдаёт большие ролики:
трейлер на полторы минуты показывается как «Media is too big», и пост выходил
без видео.

С аккаунтом бот читает каналы так же, как приложение Telegram:

- ролики любого размера (большие бот сжимает до 48 МБ — это лимит загрузки для бота);
- настоящая обложка ролика вместо чёрного первого кадра;
- полный текст поста и ссылки с кнопок.

Если аккаунт не настроен или отвалился, бот сам возвращается к веб-странице.
Сломаться из-за этого ничего не может.

## Какой аккаунт взять

Лучше отдельный аккаунт на второй номер, а не свой основной. Бот только читает
публичные каналы, на них даже не нужно подписываться. Но Telegram иногда
ограничивает аккаунты, которые работают автоматически, и свой основной лучше
не подставлять.

## Шаги (один раз)

1. **api_id и api_hash.** Зайдите с этим аккаунтом на <https://my.telegram.org>,
   откройте «API development tools» и создайте приложение. Название и адрес
   любые. Запишите `api_id` (число) и `api_hash` (строка).
2. **Строка входа.** На своём компьютере, в папке с кодом бота:

   ```
   pip install telethon
   python tools/tg_account_login.py
   ```

   Скрипт спросит api_id, api_hash, номер телефона, код из Telegram и облачный
   пароль, если он включён. В конце он напечатает длинную строку — это строка входа.
3. **Переменные на хостинге.** В панели Bothost добавьте:

   | Переменная | Что вставить |
   |---|---|
   | `TG_ACCOUNT_API_ID` | api_id |
   | `TG_ACCOUNT_API_HASH` | api_hash |
   | `TG_ACCOUNT_SESSION` | строку входа целиком |

4. **Перезапустите бота** и откройте `/status`. Должна появиться строка
   «📡 Каналы: через аккаунт Telegram 🟢».

Строку входа, api_hash и коды не отправляйте ни в чат с ботом, ни кому-либо
ещё. Строка входа — это полный доступ к аккаунту. Бот прячет её в логах и
сообщениях.

## Если что-то не так

- **В /status «аккаунт не подключён», а бот прислал причину.** Чаще всего
  строка входа скопирована не целиком или вход сброшен: в настройках аккаунта
  удалили сеанс «Telethon». Повторите шаг 2.
- **Аккаунт вышел из всех сеансов** (например, после смены пароля). Повторите шаг 2.
- **Хотите выключить.** Удалите три переменные и перезапустите бота.

## Необязательные настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TG_ACCOUNT_VIDEO_MAX_MB` | 300 | Ролики больше этого размера не скачиваются вовсе: в пост идёт обложка. |
| `TG_ACCOUNT_TIMEOUT_SEC` | 40 | Сколько ждать ответа Telegram, прежде чем перейти на веб-страницу. |
