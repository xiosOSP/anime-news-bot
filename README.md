# Anime News Bot

Telegram-бот для автопостинга аниме-новостей в канал/ветку обсуждения.

## Возможности

- Сбор новостей с 14 источников (RSS + HTML парсинг)
- Перевод на русский с защитой названий (Google Translate + AniList API)
- Дедупликация, фильтры по свежести и наличию картинок
- Blacklist стоп-слов (реклама/товарка)
- Отсев не-новостей по заголовку: подборки «10 лучших», тесты, рецензии,
  объяснялки, годовщины, скидки, фан-контент. Решение принимается на сборе,
  поэтому такой материал не занимает ни очередь, ни вызов модели.
- Отсев чужих тем без модели: у шести лент общей тематики (Collider,
  /Film, Variety, Polygon, ComingSoon, Filmix) новость идёт в канал,
  только если в заголовке или первых строках видно аниме или мангу.
  Включается там, где разбора модели нет; выключатель — в «Настройки →
  Модель и перевод», состояние видно в `/llm`.
- Режим отправки в ветку обсуждения (всё пачкой) или в канал (по одному)
- Догрузка полного текста статей со страниц
- Пачка новостей за один запрос к языковой модели: бесплатные пулы
  не выдерживают «одна новость — один вызов» (`LLM_BATCH_SIZE`)
- Метрики, логирование, retry-логика
- [Справочник переменных окружения](docs/env-reference.md) собирается из кода:
  разойтись с ним не может, инвариант следит. Свой набор переменных на живом
  боте проверяет `/doctor`, локальный детектор медиа — `/mediaping`.
- [Где взять бесплатный ключ для модели](docs/llm-providers.md) — сравнение
  бесплатных тарифов и что именно задать в переменных.
- `/llmclean` разбирает настройки модели по живым ответам провайдеров и
  говорит, что оставить, что стереть и что заменить. Слот, чей ключ отвергли,
  бот пропускает до смены ключа, а не долбит каждый цикл.
- [Локальная модерация чата](docs/chat-moderation.md): правила без LLM,
  проверка фото, GIF, стикеров и видео на наготу, учёт варнов и мутов.
- Независимые модели и бюджеты новостей и чата; мгновенная эскалация
  нарушений и обновление уведомлений вместо спама от модерации.
- Очистка статей от повторов и рекомендаций, сохранение коротких фактов,
  корректная обработка ссылок с UTM и изображений с отложенной загрузкой.

## Отказы модели и доставка

При временном отказе настроенной LLM новость остаётся в очереди. По умолчанию
бот откладывает её до трёх раз с интервалом 300 секунд; затем допускает обычный
перевод DeepL/Google. Настройки: `LLM_DEFER_MAX_ATTEMPTS` и
`LLM_DEFER_RETRY_SEC`. Отсрочка и счётчик сохраняются на диске, исходный срок
годности новости сохраняется, попытки отправки в Telegram не расходуются.

Переключение провайдера после ошибки сети, 5xx, 429 или отклонённого ключа
может обработать текущую новость в том же вызове. Повторы обработки, включая
снятие неподдерживаемых параметров, учитываются в дневной квоте и бюджете
токенов. Дополнительные параметры не могут заменить модель, сообщения или
лимит ответа и включить потоковый режим.

Для недоверенных RSS, статей и медиа соединение закрепляется за проверенными
публичными IP, каждый редирект проверяется заново. Системные HTTP-прокси для
этих запросов не используются; явный прокси отклоняется. Опциональный
`REDDIT_PROXY` в запросах к заданным адресам Reddit продолжает работать.

Если Telegram подтвердил доставку альбома, но отдельное сообщение модерации
не отправилось, пост сохраняется для ручной проверки без повторной отправки
альбома. Ошибка `BadRequest` до доставки разрешает штатную запасную отправку
изображения байтами.

## Запуск

### Переменные окружения

Обязательная:
- `BOT_TOKEN` — токен бота от @BotFather

Опциональные (есть значения по умолчанию):
- `CHANNEL_ID` — ID/username канала
- `ADMIN_ID` — Telegram ID администратора
- `DISCUSSION_CHAT_ID` — ID группы обсуждения
- `DISCUSSION_THREAD_ID` — ID темы (ветки)
- `DATA_DIR` — папка для хранения данных (для постоянного хранилища на хостинге)

### Установка и запуск

```
pip install -r requirements.txt
cp .env.example .env      # локально: впишите свои значения
python anime_news_bot.py
```

На хостинге `.env` не нужен — переменные задаются в панели.

## Тесты

```
pip install -r requirements-dev.txt
pytest
```

`tools/check_invariants.py` — тот же список инвариантов, но с читаемым выводом:
каждая строка соответствует найденной и закрытой проблеме, поэтому список может
только расти.

```
python tools/check_invariants.py
```

`BUILD_MANIFEST.json` — опись отслеживаемых файлов с хешами. Она генерируется,
а не правится руками, иначе снова разъедется с репозиторием:

```
python tools/build_manifest.py           # пересобрать после изменений
python tools/build_manifest.py --check   # сверить, ничего не записывая
```

## Команды бота

- `/start` — меню
- `/news` — свежие новости в личку
- `/preview` — превью постов
- `/start_auto`, `/stop_auto` — управление авторассылкой
- `/status` — статус
- `/stats` — метрики
- `/logs` — последние строки лога
- `/blacklist` — список стоп-слов
- `/chatinfo` — ID чата и темы
- `/settings` — настройки
