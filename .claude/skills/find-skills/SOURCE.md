# Источник

`SKILL.md` — без изменений из https://github.com/vercel-labs/skills
(`skills/find-skills/SKILL.md`), лицензия MIT, © 2026 Vercel, Inc.
Каталог навыков: https://skills.sh

Владелец попросил пользоваться этим навыком, чтобы находить нужные проекту
навыки. Поиск: `npx -y skills find <запрос>`. Найденный навык сначала
читается целиком и только потом добавляется в `.claude/skills/` вручную:
установщик `npx skills add` скачивает и запускает чужой код.
