# 🎰 РофлКазино

Демо-казино для игры с другом. Деньги **ненастоящие**: каждому игроку при входе дают 10 000 ₽,
кнопка «+10 000 ₽» добавляет ещё (а счётчик «долгов у мамы» это запоминает 🙂).

## Игры

| Игра | Режим |
|---|---|
| 📈 **Краш 1×1** | дуэль: оба ставят одинаково, кто выведет на большем иксе до краша — забирает банк |
| 💣 **Мины** | соло (с множителями) или дуэль: одинаковое поле, кто откроет больше 💎 и вовремя нажмёт «Стоп» — побеждает (мина = 0) |
| 🗼 **Башни** | соло (4 сложности) или дуэль: одинаковая башня, кто выше залез и остановился — побеждает |
| 🎡 **Рулетка** | общий стол (европейская, 0–36): числа ×36, дюжины/колонки ×3, цвет/чёт/половины ×2 |
| ✈️ **Самолётик** | общий раунд для всех, есть автовывод |
| 📦 **Кейсы** | открытие 4 кейсов (100 ₽ – 10 000 ₽) или кейс-батл с другом: у кого дроп дороже — забирает всё |

Плюс: список игроков с балансами, чат, лента событий, перевод денег другу.

## Запуск

```bash
cd casino
npm install
npm start          # http://localhost:3000
```

Порт меняется через `PORT`, файл с балансами — через `DATA_FILE` (по умолчанию `casino/data.json`).

## Как играть с другом

Другу нужен доступ к серверу. Варианты:

1. **Бесплатный хостинг (Render.com):** New → Web Service → подключить этот репозиторий,
   *Root Directory* = `casino`, *Build Command* = `npm install`, *Start Command* = `npm start`.
   Получите ссылку вида `https://xxx.onrender.com` — кидаете её другу.
   (На бесплатном тарифе сервер засыпает и при перезапуске балансы сбрасываются — для рофла норм.)
2. **С домашнего компьютера:** запустить `npm start`, затем `npx cloudflared tunnel --url http://localhost:3000`
   (или ngrok) — получите публичную ссылку для друга.
3. **В одной Wi-Fi сети:** другу достаточно открыть `http://<ваш-локальный-IP>:3000`.

Вход — по нику; ник привязывается к браузеру, так что занять чужой не получится.
